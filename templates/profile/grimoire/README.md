# {{name}}'s Grimoire

The approved knowledge every agent {{name}} runs starts with: Pi through sitra, and Claude Code and Codex after
`sitra grimoire install`. Plain markdown; agents propose, {{name}} approves.

- `root/`: always loaded. Keep it short and high level: who {{name}} is and what they're building, the decisions that
  shape the work, and how they like to work. Every agent reads all of it at the start of every session.
- `kinds/`: approved entries (decisions, facts, lessons, setups, warnings). Agents see a one-line catalogue of them and
  open the ones that apply.
- `proposals/`: what agents suggested. Review them in Pi with `/grimoire`.
- `rejected/`: what {{name}} turned down, kept so nobody suggests it again.

`sitra grimoire status` shows the sizes; `sitra grimoire search "<words>"` finds entries. See sitra's
`docs/GRIMOIRE.md` for the entry format.
